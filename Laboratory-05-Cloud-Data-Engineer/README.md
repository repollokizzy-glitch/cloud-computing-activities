# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This mission focuses on cloud data engineering and object storage. I learned how different types of cloud storage work and deployed MinIO using Docker as an S3-compatible object storage server.

## Objectives

- Understand Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access the MinIO Web Console.
- Create an object storage bucket.
- Upload a sample file.
- Document the deployment process.

## Tools Used

- GitHub
- KillerCoda Ubuntu Playground
- Docker
- MinIO
- Linux Command Line
- Web Browser

## Skills Learned

- Comparing different cloud storage types
- Deploying containerized services
- Using Docker environment variables
- Accessing services through ports
- Creating and managing object storage buckets
- Documenting cloud deployments using Markdown
