# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers services for computing, storage, databases, networking, data analytics, artificial intelligence, and application development.

## Global Infrastructure

Google Cloud operates a global infrastructure consisting of Regions and Zones. Its infrastructure is designed to provide scalable, reliable, and highly available cloud services.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud projects, resources, services, monitoring, and security.

## Four Core Services

1. **Compute Engine** – Provides virtual machines for running applications.
2. **Cloud Storage** – Provides scalable object storage.
3. **Cloud SQL** – Provides managed relational databases.
4. **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes clusters.

## Three Advantages

1. Strong artificial intelligence and machine learning capabilities.
2. Excellent Kubernetes and container support.
3. Powerful data analytics services.

## Typical Enterprise Use Cases

GCP is commonly used for artificial intelligence, machine learning, big data analytics, containerized applications, web applications, and cloud-native development.
