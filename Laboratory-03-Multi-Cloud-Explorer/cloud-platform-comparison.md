## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest and most mature portfolios of cloud services. It provides services covering computing, storage, networking, databases, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works closely with services such as Windows Server, Microsoft 365, Active Directory, and other Microsoft enterprise technologies.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in artificial intelligence, machine learning, data analytics, and Kubernetes. Its Google Kubernetes Engine (GKE) provides a managed Kubernetes environment for containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a wide range of services and gives users many options for building and deploying applications. Its large ecosystem also provides useful opportunities for learning different cloud technologies.
