# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think storage is one of the most important cloud infrastructure components because applications need a place to keep their data and files. Processing power is useful, but the system would have problems if important information could not be stored safely. Reliable storage helps applications keep the information they need.

## 2. How does Linux support cloud computing?

Linux provides an operating system that can be used to run cloud servers and applications. It also provides command-line tools that allow administrators to inspect and manage server resources. In this activity, Linux commands helped me examine the CPU, memory, storage, filesystem, and network information.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation gives engineers a clear record of the planned infrastructure and its resources. It can also be used later when troubleshooting or modifying the system. Good documentation helps prevent mistakes and makes it easier for other team members to understand the environment.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using different terminal commands. I also learned more about the relationship between compute, storage, networking, and operating systems in cloud infrastructure. Another skill I practiced was creating Markdown documentation and a basic cloud architecture diagram.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized and useful after completing this mission. It now contains an infrastructure investigation, cloud component explanations, a comparison of major cloud providers, a cloud architecture diagram, and a reflection. These files provide evidence of the technical skills I practiced during the laboratory.
